# Compta SYSCOHADA (PWA + GitHub BDD + Export CSV/PDF)

## Contenu de l'archive
- `index.html` : Application comptable SYSCOHADA complète avec synchronisation GitHub (`GitHubBridge`), export PDF (`jsPDF`) et export CSV/Excel (`UTF-8 BOM`).
- `manifest.json` : Configuration Progressive Web App (PWA) pour installation mobile.
- `sw.js` : Service Worker de mise en cache des ressources.

## Déploiement rapide sur GitHub Pages
1. Décompressez cette archive dans votre dépôt GitHub.
2. Poussez les fichiers sur la branche `main`.
3. Activez **Settings > Pages** sur la branche `main`.
4. Ouvrez l'URL sur votre smartphone et cliquez sur **Ajouter à l'écran d'accueil**.
